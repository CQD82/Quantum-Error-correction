Rotated surface code · distance 5

Find the error without looking at the qubit.

Quantum error correction measures parities of neighbouring qubits, never the qubits themselves. An error lights up the checks around it. A decoder reads that pattern and works out a correction without collapsing the stored information.

  1. InjectClick a data qubit to apply an X, Z or Y error.
  2. MeasureChecks that anticommute with the error light up as defects.
  3. DecodeMinimum-weight matching pairs defects and applies a correction.

Code atlas

[[n, k, d]]: n physical qubits encode k logical qubits, and the code detects any error on fewer than d qubits.

Code[[n, k, d]]FamilyWhy it matters
Bit-flip repetition[[3,1,1]]RepetitionMajority vote for qubits. Corrects one X error but no phase errors.
Shor code[[9,1,3]]ConcatenatedFirst quantum code to correct an arbitrary single-qubit error (1995).
Steane code[[7,1,3]]CSS · colour codeEvery Clifford gate is transversal, which makes fault-tolerant logic simple.
Five-qubit code[[5,1,3]]Cyclic stabilizerSmallest code that corrects any single-qubit error. Saturates the quantum Hamming bound.
Rotated surface code[[d²,1,d]]Topological · CSSOnly nearest-neighbour checks on a square grid, and a threshold near 1% under circuit-level noise.
Bivariate bicycle ("gross") code[[144,12,12]]Quantum LDPCStores 12 logical qubits at distance 12 in 144 data qubits, at the cost of long-range connections.

Timeline

From theory to below threshold

  1. 1995

    Shor's nine-qubit code. Shows that quantum information can be protected despite the no-cloning theorem.

  2. 1996

    Steane code and the five-qubit code. CSS construction links quantum codes to classical linear codes.

  3. 1997

    Kitaev's toric code; Gottesman's stabilizer formalism. Topological protection and the algebra used by every tool on this page.

  4. 2012

    Fowler et al., "Surface codes: Towards practical large-scale quantum computation." The standard reference for surface code resource estimates.

  5. 2023

    Google Quantum AI scales a logical qubit from d = 3 to d = 5 and sees the logical error rate fall slightly. Harvard and QuEra run circuits on up to 48 logical qubits in neutral atoms.

  6. 2024

    Below threshold. Google reports a distance-7 surface code memory whose logical error rate drops by a factor of Λ ≈ 2.14 each time the distance grows by two. IBM proposes the [[144,12,12]] gross code.
